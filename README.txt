KANOON MITRA — LEGAL LIBRARY
=============================

Files
-----
- law-library.html : mobile-friendly library page and styling
- laws.json       : sample law/article records
- cases.json      : sample case-law records
- script.js       : loads JSON, search, filters, and detail modal

Install on GitHub Pages
-----------------------
1. Open your repository: https://github.com/rakeshgodara1061/kanoon-mitra
2. Download/backup your existing law-library.html first.
3. Upload these four files to the repository root (same folder as index.html).
4. If GitHub asks whether to replace law-library.html, replace it only after backing up the old file.
5. Commit directly to the main branch.
6. Open https://rakeshgodara1061.github.io/kanoon-mitra/law-library.html
7. If old content appears, refresh or open in an incognito tab.

Important
---------
- This starter includes illustrative sample records, not an exhaustive legal database.
- The official source links are broad portals; they may not open the exact provision.
- Check the current text, amendments, commencement dates, and judgments before publishing.
- Do not treat these summaries as personal legal advice.
- JSON must remain valid. If adding a record, follow the same field structure and do not leave a trailing comma.
- The page uses relative paths (./laws.json, ./cases.json, ./script.js), so it works in a GitHub Pages project site.
